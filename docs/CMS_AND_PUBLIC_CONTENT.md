# CMS And Public Content

Avomeal public content should support a food/store brand, not generic VNV Events services.

## Public Topics

CMS pages, blog posts and SEO content may cover:

- meal preps,
- holiday menus,
- party boxes,
- appetizers,
- sweets,
- dinner kits,
- nutrition,
- healthy meals,
- event food,
- delivery,
- subscriptions,
- seasonal menus.

## SEO Rules

Public pages should include:

- server-rendered visible content,
- title,
- meta description,
- canonical URL,
- Open Graph metadata,
- JSON-LD where safe,
- internal links,
- sitemap inclusion only when published/indexable.

Do not invent ratings, reviews, addresses, offices, prices or claims that are not real.

## Owner Scope

CMS content that is Avomeal-specific should be attached to owner `2` or otherwise clearly classified as Avomeal content.

Inherited VNV Events pages can remain as reference routes, but they should not be used as Avomeal positioning copy unless intentionally adapted.
