# Homepage Positioning

The Avomeal homepage should explain the modern brand clearly:

```text
Avomeal helps customers enjoy prepared meals, seasonal menus and party-ready food boxes without the stress of planning everything from scratch.
```

## Required Story

The homepage should communicate:

- Avomeal is not only meal prep.
- Avomeal helps with weekly meals and celebrations.
- The three pillars are meal preps, holiday menus and party boxes.
- Customers can buy individual products or use recurring/subscription options.
- Minimum order is `$65`.
- Avomeal is connected to VNV Events but keeps its own food-brand identity.

## Suggested Hero Copy

```text
Prepared meals, holiday menus and party boxes for South Florida.
```

Supporting copy:

```text
Avomeal helps you plan the food side of busy weeks, family celebrations and small events with chef-prepared meals, seasonal menus, appetizer boxes, sweets, dinner kits and subscription-friendly options.
```

## Calls To Action

- Shop meals and boxes.
- Build a meal plan.
- View holiday menus.
- Request a custom food package.

## Public Copy Rules

- Use Avomeal as the brand.
- Mention VNV Events only as the parent/connected event operation when helpful.
- Do not make Avomeal sound like generic Ophyra.
- Do not describe the brand as only meal prep.
- Make the `$65 minimum order` easy to find.
